Documentation

Version: 2.2.1 (Forge / Marketplace)

What it does

Ticket Quality Auditor scores Jira issues for completeness, clarity, testability, and actionable requirements. It surfaces findings and recommendations in an Issue Panel and can optionally suggest improved ticket text for you to review before applying.

Install

  1. Install from Atlassian Marketplace (Jira Cloud).
  2. Grant requested permissions (read:jira-work, write:jira-work, storage:app).
  3. Open Admin to confirm project / issue-type filters (defaults work immediately).
  4. Open any issue → Ticket Quality panel → Analyze Ticket.

Issue Panel

  • Analyze / Re-analyze — run rules + optional Forge LLMs analysis
  • Improve Ticket — generate a proposed rewrite; apply only after explicit confirmation
  • Scores are 0–100 with quality levels (Excellent / Good / Needs Improvement / Poor)

Admin configuration

  • Enable/disable product, AI, and Improve Ticket
  • Automation on create/update + minimum interval
  • Project and issue-type filters
  • Scoring model version and thresholds

Permissions

  • read:jira-work — read issue fields for analysis
  • write:jira-work — apply confirmed Improve Ticket updates; optional comments
  • storage:app — store config and analysis results in Forge storage

Privacy & AI

Analysis results are stored in Forge app storage. When AI is enabled, selected ticket text is processed by Atlassian-hosted Forge LLMs (no third-party AI egress). See the Privacy Policy.
