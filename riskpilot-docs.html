RiskPilot

Version: 1.0.0 · Jira Cloud · Atlassian Forge

What it does

RiskPilot scores delivery risk at issue, project, and portfolio levels. It surfaces signals, recommendations, release exposure, and emerging trends in a dashboard gadget and issue panel. Optional AI explanations use Atlassian-hosted Forge LLMs only (Runs on Atlassian).

Install

  1. Install from Atlassian Marketplace (Jira Cloud, Paid via Atlassian).
  2. Grant permissions: read:jira-work, write:jira-work (optional comments), storage:app.
  3. Open RiskPilot Admin to select monitored projects and thresholds.
  4. Add the RiskPilot dashboard gadget and refresh portfolio analysis.

Dashboard

  • Overview — portfolio score, exposure mix, delivery profile, drivers, outcomes
  • Risks — register with Monitor / Mitigate / Resolve
  • What-if — scenario simulator
  • Insights — Forge LLM assistant (portfolio, dependencies, focus areas)

Issue panel

  • Unified risk profile chart and recommendations
  • Accept recommendations and re-analyze to measure outcomes

Admin

  • Projects, analysis schedules, risk thresholds, dimension weights
  • AI and assistant toggles; optional Jira audit comments

Permissions

  • read:jira-work — read issues and links for analysis
  • write:jira-work — optional comments when enabled in admin
  • storage:app — Forge storage for config and analysis results

Privacy & AI

Results are stored in Forge app storage for your site. When AI is enabled, structured context is sent to Forge LLMs on Atlassian infrastructure. See the Privacy Policy.
