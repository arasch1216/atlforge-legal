RiskPilot — getting started

  1. Install from Atlassian Marketplace.
  2. Open RiskPilot Admin to select monitored projects.
  3. Add the dashboard gadget and run Refresh portfolio analysis.
  4. Open an issue → RiskPilot panel → Analyze with RiskPilot.

Ticket Quality Auditor — getting started

  1. Install from Atlassian Marketplace.
  2. Open Admin to configure projects and automation.
  3. Open any issue → Ticket Quality panel → Analyze Ticket.

Common issues

All apps: Confirm you installed the correct Marketplace listing and that licensing is active for paid apps.

RiskPilot: Refresh portfolio analysis after config changes; check project keys in Admin; Insights requires a saved portfolio snapshot.

Ticket Quality: Re-analyze after major edits; Improve Ticket requires issue edit permission; disable AI in Admin if LLM is unavailable (deterministic mode still works).
