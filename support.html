Customer Support

Support for Ticket Quality Auditor (for Jira Cloud) is provided by AD Lab Development during business hours (Mon–Fri, US time zones).

Customer support portal

Open a support request in our Jira Service Management portal: adhayes.atlassian.net/servicedesk/customer/portal/1

Target first response: within two business days.

Email

support@adlabdevelopment.com

Include your Atlassian site URL, app version, issue key (if relevant), and steps to reproduce. Do not send API tokens or passwords.

Install / first use

  1. Install from Atlassian Marketplace.
  2. Grant the requested Jira permissions.
  3. Open Admin to configure projects, automation, and AI (defaults work immediately).
  4. Open a Jira issue → Ticket Quality panel → Analyze Ticket.

Full setup guide: Documentation

Common issues

  • AI unavailable: Deterministic analysis still works. Retry later or disable AI in Admin.
  • Permission errors on Improve Ticket: User needs issue edit permission; reinstall may be required after scope changes.
  • Stale score: Click Re-analyze after major ticket edits.
  • No automatic analysis: Check project/issue-type filters and automation settings in Admin.

Security issues

Report vulnerabilities to security@adlabdevelopment.com. See Security Policy.
