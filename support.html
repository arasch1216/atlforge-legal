Install / first use

  1. Install the App from Atlassian Marketplace (or via approved Forge install for testing).
  2. Grant the requested Jira permissions.
  3. Open Admin → configure projects / automation / AI if needed (defaults work out of the box).
  4. Open a Jira issue → open the Ticket Quality panel → Analyze Ticket.

Common issues

  • AI unavailable: Deterministic analysis should still work. Re-try later or continue without AI suggestions.
  • Permission errors on Improve Ticket: An admin may need to upgrade the app install to grant write permission.
  • Stale score: Click Re-analyze after major ticket edits.
  • Issue not analyzed automatically: Check project / issue-type filters and automation settings in Admin.
